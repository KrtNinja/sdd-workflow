# sdd-lint — проверка и текущий этап

Вход: slug фичи. Нет slug — посмотри папки в `docs/` и спроси.

1. Запусти из корня репозитория с доками:
   `node <папка этого скилла>/scripts/sdd-lint.mjs docs/<feature>`
2. Выведи результат как есть: ошибки, предупреждения и строку этапа.
3. Ошибки есть — предложи, каким скиллом их исправить: решения — `/sdd-decide`, остальное — правкой
   файла. Остановись.

Другие sdd-скиллы вызывают этот же скрипт: от их папки путь —
`../sdd-lint/scripts/sdd-lint.mjs`. Нужен Node 18+.
